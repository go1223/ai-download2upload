# 声取 MediaDock

本地部署的轻量媒体工作台：**B 站搜索下载 + 多平台链接下载 + 网易云播客上传**。  
原生 H5 界面，手机、平板、桌面浏览器都能用；无需任何云端 API Key。

## 功能

- B 站关键词搜索，展示封面、UP 主、时长、播放量。
- 视频下载：最佳画质视频轨 + 音频轨，ffmpeg 合并为 `.mp4`。
- 音频下载：提取音轨并转码为 `.mp3`。
- 粘贴链接下载：支持 B 站、YouTube、TikTok、X 等 yt-dlp 可解析平台。
- 网易云播客：读取账号下可管理的播客列表，选择文件上传到指定播客。
- 任务进度、速度、ETA、结果文件下载；任务记录持久化。
- 手机/平板自适应；支持局域网访问。

## 快速启动（Windows）

### 第一次

1. 安装 **Python 3.9+**：<https://www.python.org/downloads/>，安装时勾选 `Add python.exe to PATH`。
2. 安装 **ffmpeg**（必需）：
   ```powershell
   winget install Gyan.FFmpeg
   ```
   或下载 ffmpeg，把 `ffmpeg.exe`、`ffprobe.exe` 放到项目的 `bin\` 目录。
3. 双击 **`start.bat`**。首次会自动安装 Python 依赖。
4. 浏览器会自动打开 <http://127.0.0.1:8765>。

### 以后每次启动

双击 **`start.bat`** 即可。关闭黑色命令行窗口即停止服务。

### 手机 / 平板访问

1. 电脑和手机连接同一个 Wi-Fi。
2. 双击 **`start-lan.bat`**。
3. 命令行窗口会打印类似 `局域网访问: http://192.168.1.23:8765` 的地址，在手机浏览器打开。
4. 如果 Windows 弹出防火墙提示，请勾选“专用网络”并允许。

> 局域网模式会监听 `0.0.0.0`，仅建议在可信家庭/办公网络使用，不要直接暴露到公网。

### macOS / Linux

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

需要系统已安装 `ffmpeg`。默认地址 <http://127.0.0.1:8765>。

## 网易云播客如何连接

上传功能使用网易云网页端登录态，不需要账号密码，也不会把 Cookie 写入服务端磁盘。

1. 浏览器打开 <https://music.163.com/> 并登录（账号需已开通播客/主播权限）。
2. 按 `F12` → **Network / 网络** → 刷新页面。
3. 点任意请求，在 **Request Headers** 中找到 **Cookie**，复制整段。
4. 确认包含 `MUSIC_U` 和 `__csrf`，粘贴到「播客上传 → 网页 Cookie」。
5. 点「读取我的播客」，选择目标播客，选择音频并上传。

关闭「上传后自动发布」时，节目会以私密/未发布状态提交，可稍后到网易云创作中心检查并发布。  
Cookie 只保存在当前浏览器的 `localStorage`；换浏览器或清除站点数据后需要重新粘贴。

## B 站高清 / 风控

B 站未登录通常只能取到 480P/720P；触发搜索风控时可能返回 `-412`。  
在「下载工坊 → 高级设置」粘贴 B 站 Cookie（同样只存本机浏览器），可提高成功率并获取更高画质（取决于账号权限）。视频下载会优先选择 H.264 视频轨，兼容性更好。

## 常用配置

通过环境变量调整：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 监听地址；局域网用 `0.0.0.0` |
| `PORT` | `8765` | 端口 |
| `FFMPEG_PATH` | 自动查找 | 指定 ffmpeg 可执行文件或目录 |
| `OPEN_BROWSER` | `0` | `1` 时启动后自动打开浏览器 |

PowerShell 示例：

```powershell
$env:PORT=9000; python app.py
```

## 常见问题

**页面提示“缺少 ffmpeg”**  
安装 ffmpeg 后重新打开命令行窗口；或把 `ffmpeg.exe` 放入 `bin\`。MP4 合并与 MP3 转码必须依赖它。

**B 站搜索报“触发风控”**  
稍等几分钟再试，或在高级设置填入 B 站 Cookie。

**网易云提示 Cookie 无效 / 301**  
重新登录 music.163.com 并复制最新 Cookie；确认包含 `MUSIC_U` 与 `__csrf`。

**读取不到播客**  
确认账号已开通播客/主播权限，并能在网易云创作中心看到自己的播客。

**手机打不开局域网地址**  
确认同一 Wi-Fi、Windows 防火墙允许 Python 的专用网络访问，并使用 `start-lan.bat` 启动。

**下载很慢或失败**  
B 站/其它平台网络波动、地区限制或登录态不足都可能导致失败；任务卡会展示具体错误。
