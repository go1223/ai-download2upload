# 声取 MediaDock · 项目需求文档

> 版本：v1.0（2026-10-28）  
> 定位：本地部署、手机/平板可用的轻量媒体下载与播客上传 Web 工作台。

## 1. 项目概述

### 1.1 一句话描述

输入关键词或链接，下载 B 站及 yt-dlp 支持平台的视频/音频；再把音频选择上传到网易云音乐播客的指定节目。

### 1.2 目标用户

- 需要在电脑、手机或平板上快速保存素材的内容创作者。
- 需要把录音/音频上传到网易云播客，但不想反复打开电脑客户端的主播。
- 希望通过浏览器访问本地服务，而不是安装桌面软件的用户。

### 1.3 AI 定位说明

本版本不依赖任何大模型或云端 AI 服务，避免 API Key 成本与隐私风险。  
所有能力通过稳定的 JSON API 暴露，后续可被 AI Agent 直接调用；本期不实现自然语言对话入口。

## 2. 功能需求

### 2.1 P0：B 站视频搜索与下载

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F-01 | 关键词搜索 | 输入关键词，返回 B 站视频列表，含封面、标题、UP 主、时长、播放量、发布日期、BV 号 |
| F-02 | 分页 | 支持上一页/下一页，单页 20 条 |
| F-03 | 视频下载 | 选择视频后下载最佳画质，自动合并视频轨+音频轨，输出 `.mp4` |
| F-04 | 音频下载 | 选择音频后提取音轨，转码输出 `.mp3` |
| F-05 | 下载进度 | 展示下载百分比、速度、ETA、阶段（解析/下载/合并/完成） |
| F-06 | 文件取回 | 任务完成后可在网页直接下载文件 |
| F-07 | 链接下载 | 粘贴 B 站链接/BV 号，选择 MP4 或 MP3 后开始任务 |

### 2.2 P0：网易云播客上传

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F-08 | 登录态 | 用户粘贴网易云网页 Cookie；仅保存在浏览器 localStorage，不写入服务端磁盘 |
| F-09 | 获取播客列表 | 连接后读取当前账号可管理的播客/声音列表，展示封面、名称、声音数 |
| F-10 | 选择目标播客 | 单选一个目标播客，上传时带上其 `voiceListId`、分类、封面等字段 |
| F-11 | 选择音频文件 | 支持点击/拖拽选择 mp3、flac、wav、m4a；非 mp3/flac 自动转 mp3 |
| F-12 | 填写节目信息 | 标题（默认取文件名）、简介、是否上传后自动发布 |
| F-13 | 上传进度 | 展示准备、上传、发布三个阶段与百分比 |
| F-14 | 错误提示 | Cookie 失效、无播客权限、文件过大、网络失败时给出可操作提示 |

### 2.3 P1：多平台下载

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F-15 | 通用链接下载 | 通过 yt-dlp 支持 YouTube、TikTok、X、Vimeo 等平台；以实际 yt-dlp 支持范围为准 |
| F-16 | 平台识别 | 任务卡展示来源平台（Bilibili、YouTube 等） |
| F-17 | 链接校验 | 只允许 http/https，阻止 localhost、内网 IP、file:// 等 SSRF 风险 |

### 2.4 P1：体验与部署

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F-18 | 响应式 H5 | 360px 手机到桌面宽度均可操作；触控目标 ≥ 40px |
| F-19 | 本地部署 | Windows 双击 `start.bat` 启动；局域网访问使用 `start-lan.bat` |
| F-20 | 依赖自检 | 启动时检测 Python、Flask、yt-dlp、pycryptodome、ffmpeg |
| F-21 | 任务持久化 | 任务元数据写入 `data/jobs.json`；服务重启后历史任务仍可见 |
| F-22 | 无密钥运行 | 不配置任何云端 API Key 即可使用 B 站搜索/下载与网易云上传 |

### 2.5 本期不做（Out of Scope）

- 网易云二维码/手机号登录（本期用 Cookie，避免保存账号密码）。
- 除网易云外的播客平台真实上传（仅保留扩展位）。
- 批量下载播放列表、字幕、封面嵌入、去水印。
- 用户系统、多人权限、公网部署、HTTPS 证书。
- 大模型对话、语音识别、AI 剪辑。

## 4. 技术方案

| 层 | 选型 | 原因 |
| --- | --- | --- |
| 后端 | Python 3.9+ / Flask | 轻量、单文件路由、易部署 |
| 下载 | yt-dlp + ffmpeg | 覆盖 B 站与大量平台，合并/转码成熟 |
| B 站搜索 | B 站 Web 搜索接口 | 无需官方 Key；带 Cookie 可降低风控 |
| 网易云 | weapi（AES + RSA）+ Web 上传接口 | 无官方公开上传 API，复用网页端协议 |
| 前端 | 原生 HTML/CSS/JS | 无构建步骤、体积小、离线可用 |
| 任务 | 线程 + 内存状态 + JSON 快照 | 本地单用户足够，避免引入 Redis/Celery |

### 4.1 目录结构

```
.
├─ app.py                  # Flask 入口与全部 API
├─ web/
│  ├─ index.html           # 单页界面
│  ├─ app.css              # 响应式样式
│  └─ app.js               # 交互与轮询
├─ docs/需求文档.md
├─ downloads/              # 下载文件（运行时生成）
├─ uploads/                # 待上传临时文件（运行时生成）
├─ data/jobs.json          # 任务快照（运行时生成）
├─ requirements.txt
├─ start.bat
├─ start-lan.bat
└─ README.md
```

### 4.2 核心流程

**下载：**

```
搜索关键词 → B 站搜索接口 → 用户点 MP4/MP3
→ 创建 job → 后台线程 yt-dlp
→ ffmpeg 合并/转码 → 文件落盘 → 前端轮询 → 下载
```

**上传：**

```
粘贴 Cookie → voicelist/search → 选择播客
→ 选择音频 + 填标题 → 原始二进制上传到本地服务
→ weapi 申请 NOS Token → 分片上传到网易云对象存储
→ preCheck → batch/upload/v2 → 完成
```

## 5. API 设计

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/health` | 依赖与版本自检 |
| GET | `/api/search/bilibili?q=&page=` | B 站搜索 |
| POST | `/api/inspect` | 解析链接元信息 |
| POST | `/api/download` | 创建下载任务 |
| GET | `/api/jobs` | 任务列表 |
| GET | `/api/jobs/<id>` | 单任务状态 |
| GET | `/api/jobs/<id>/file` | 下载结果文件 |
| POST | `/api/netease/podcasts` | 获取播客列表（Header: `X-Netease-Cookie`） |
| POST | `/api/netease/upload` | 创建上传任务（原始文件流 + 查询参数 + Cookie Header） |

### 5.1 关键请求示例

```http
POST /api/download
Content-Type: application/json

{"url":"https://www.bilibili.com/video/BV1xx411c7mD","mode":"audio"}
```

```http
POST /api/netease/podcasts
X-Netease-Cookie: MUSIC_U=...; __csrf=...
```

```http
POST /api/netease/upload?filename=a.mp3&title=第1期&voiceListId=123&autoPublish=0
X-Netease-Cookie: MUSIC_U=...; __csrf=...
Content-Type: application/octet-stream

<二进制音频>
```

## 6. 数据与安全

- **Cookie 不落盘**：网易云/B 站 Cookie 只存在浏览器 `localStorage`，请求时通过 Header 传给本地服务；服务端只放在内存任务中，任务结束即丢弃。
- **任务快照不含密钥**：`data/jobs.json` 只存任务元信息、文件名、状态，不存 Cookie。
- **路径安全**：文件只写入固定 `downloads/<uuid>/`、`uploads/<uuid>/`，文件名经清洗，禁止路径穿越。
- **SSRF 防护**：链接仅允许 http/https，拒绝 localhost、`.local`、私有/保留 IP。
- **上传大小限制**：默认 500MB，前端与服务端双重校验。
- **版权**：仅下载本人拥有版权或已获授权的素材；遵守平台服务条款。

## 7. 验收标准

### 7.1 下载

- [ ] 搜索“小猫”返回 ≥ 10 条结果，封面/标题/时长正常显示。
- [ ] 选择任一视频 MP4，任务从 0% 到 100%，产物为可播放 `.mp4`，含画面和声音。
- [ ] 选择 MP3，产物为可播放 `.mp3`，时长与原视频一致。
- [ ] 粘贴 B 站链接/BV 号同样可下载。
- [ ] 下载完成后点击“保存文件”能取回文件。
- [ ] 服务重启后历史任务仍显示。

### 7.2 上传

- [ ] 无 Cookie 时提示“请先连接网易云”，不发起无效上传。
- [ ] 有效 Cookie 能列出账号下可管理的播客。
- [ ] 选择 mp3 后可上传，进度可见，成功/失败有明确提示。
- [ ] 上传成功后网易云创作中心能看到对应声音（自动发布关闭时在草稿/未发布列表）。
- [ ] Cookie 失效时提示重新获取，不泄露 Cookie 内容。

### 7.3 响应式

- [ ] 375px 宽度无横向滚动，搜索、下载、上传均可完成。
- [ ] 768px 平板双列卡片布局正常。
- [ ] 桌面 1280px 内容居中，最大宽度受控。

### 7.4 启动

- [ ] 双击 `start.bat` 自动安装缺失依赖并打开浏览器。
- [ ] 缺少 ffmpeg 时页面给出明确安装提示，而不是静默失败。
- [ ] `start-lan.bat` 启动后，同一 Wi-Fi 下手机可访问局域网地址。

## 8. 风险与边界

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| B 站搜索接口风控 | 搜索返回 -412 | 提示稍后重试；支持填 Cookie 降低风控 |
| B 站高清需登录 | 仅能拿到 480P/720P | 高级设置填 B 站 Cookie；大会员账号可提升 |
| 网易云 Web API 变更 | 列表/上传失败 | 错误原样提示；接口集中在 `netease_*` 函数，便于更新 |
| Cookie 过期 | 上传 301/未登录 | 提示重新粘贴 Cookie |
| 音频格式不支持 | 上传失败 | 非 mp3/flac 先 ffmpeg 转 mp3 |
| 大文件上传超时 | 任务失败 | 流式上传、500MB 上限、超时 300s |
| 平台版权/条款 | 账号风险 | 仅限个人授权素材，不提供去水印/批量抓取 |
