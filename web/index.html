尚未连接官方平台

官方平台凭据怎么来？
  1. 在 网易云开放平台 完成开发者入驻并创建应用。
  2. 在应用详情获取 appId、appSecret 和 privateKey，并确认已申请“播客相关能力”。
  3. 打开 H5 授权页并完成登录授权，浏览器会跳转到你配置的回调地址，地址里带 code=...。
  4. 把该 code 填到「授权 code」，点“用 code 获取 accessToken”，然后连接。
  5. 也可直接粘贴已有 accessToken。accessToken 默认 7 天过期，失效后重新用 code 获取。

授权调试工具：st.music.163.com/g/oauth-tool · code 换 accessToken 文档

仅读取你自己的播客与声音；播放/下载权限取决于开放平台账号、会员和接口组审批。

本地运行说明

01

手机 / 平板访问

双击 start-lan.bat，让手机与电脑连同一 Wi-Fi，打开窗口里显示的局域网地址。

02

ffmpeg 必需

MP4 合并与 MP3 转码依赖 ffmpeg。页面顶部状态会显示是否就绪，未安装时请先加入 PATH。

03

只处理授权内容

请仅下载本人拥有版权或已获授权的素材；上传与发布行为需遵守平台条款，账号风险由使用者承担。
